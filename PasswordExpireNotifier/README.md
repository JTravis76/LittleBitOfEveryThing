# Password Expire Notifier

```bat
:: to install window service
C:\Windows\Microsoft.NET\Framework\v4.0.30319\installutil /user=domain\administrator /password=<PASSWORD> PasswordExpireNotifier.exe
pause

:: to uninstall window service
::C:\Windows\Microsoft.NET\Framework\v4.0.30319\installutil PasswordNotify.NotifyService.exe /u
```
