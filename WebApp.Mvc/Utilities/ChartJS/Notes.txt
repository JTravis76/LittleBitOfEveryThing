This ChartJs class is a .Net wrapper for popular ChartJS found here.
http://www.chartjs.org
ChartJs builds wonderful looking charts using jQuery.


Here a developer designed a .NET wrapper to generate charts using the popular Chart.Js library
https://github.com/martinobordin/Chart.Mvc
Problem: was design for ChartJs ver 1.0.
Also, was having namespace confilct.


This developer forked the project to clear the nampspace issue.
https://github.com/cigano/ChartJs.Mvc

Since both projects used ChartJs v1.0, I thought I would use their concept and
rebuild wrapper for ChartJs v2.0
